# CBNU Research Group Website

충북대학교 정보통신공학부 **인간-컴퓨터 상호작용(HCI) 연구실**과 소프트웨어학부 **데이터 마이닝(DM) 연구실**의 공식 웹사이트 리포지토리입니다.

---

## 1. 개요 및 목적 (Overview)

본 웹사이트는 충북대학교 HCI & DM 공동 연구 그룹의 비전, 교수진 및 연구원 소개, 최신 연구 논문(Publications) 목록, 연구실 공지 및 학술 행사 소식을 공유하기 위해 제작되었습니다.

- **공식 배포 웹사이트**: [https://mywange.github.io/cbnu-research-web/](https://mywange.github.io/cbnu-research-web/)
- **소속**: 충북대학교 정보통신공학부 / 소프트웨어학부
- **연구 분야**:
  - **HCI Lab**: Human-AI Interaction, Computing for Well-being, Embodied Interaction in XR, Behavioral Sensing & Modeling
  - **DM Lab**: Graph Mining using LLMs, Text Mining using LLMs, AI for Healthcare

---

## 2. 주요 페이지 구성

- **About**: 공동 연구 그룹의 연구 철학(Discover, Design, Disseminate) 및 세부 연구실 소개
- **Publications**: 세계 유수 국제 학술대회(ACM CHI, KDD, CIKM, UbiComp, WWW 등) 및 저널 게재 논문 목록 및 검색/필터링
- **People**: 교수진, 석사과정 연구원, 학부 연구생 정보 및 연락처
- **News & Events**: 최신 공지사항, 연구실 소식 및 학술 세미나/워크숍 안내
- **Gallery**: 연구 활동 및 학술대회 현장 사진

---

## 3. 기술 스택

- **Frontend**: HTML5, Vanilla CSS, Vanilla JavaScript
- **Data Format**: Markdown (.md), JSON (.json)
- **Hosting**: GitHub Pages
